# 🏦 ATM Interface Project (Java)

## 📌 Project Description

This is a **console-based ATM Interface** developed in Java.
It simulates basic ATM operations such as login, deposit, withdrawal, transfer, and transaction history.

---

## 🚀 Features

* 🔐 User Authentication (User ID & PIN)
* 💰 Withdraw Money
* 💵 Deposit Money
* 🔄 Transfer Money
* 📜 Transaction History
* 💳 Balance Inquiry
* 🚪 Exit Option

---

## 🛠️ Technologies Used

* Java (Core Java)
* VS Code
* Git & GitHub

## ▶️ How to Run

### 🔹 Compile

```

```

### 🔹 Run

```
java ATM
```
